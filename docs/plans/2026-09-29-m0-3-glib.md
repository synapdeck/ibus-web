# M0.3: GLib for WASM — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build nixpkgs' GLib 2.88.3 (GLib, GObject, GIO, GRegex) for WASM
through `pkgsWasm`, with an Emscripten patch series applied by an overlay, and
run GLib's own test suite under Node with a baseline that decides which
results gate `nix flake check`.

**Architecture:** `pkgsWasm` tells Meson the host system is `emscripten`
(an extra cross file from a stdenv setup hook, which also gives Meson Node as
its exe wrapper). The patch series comes from Kleis Auke Wolthuizen's
`wasm-vips-2.88.1` branch of GLib, rebased onto 2.88.3 without its GRegex
removal, and lives in `modules/glib/`, whose `overlay.nix` defines
`flake.overlays.glib`. A second check builds GLib with its tests enabled,
runs `meson test` under Node, and compares the results with a committed
baseline.

**Tech stack:** Nix flakes, flake-parts, nixpkgs cross compilation, Meson,
Emscripten 6.0.9, Node, GLib 2.88.3, pcre2, Python (for the baseline gate).

**Scope:** Third slice of M0. Not in this plan: `libibus-web`, the runtime
main module and its export list, the Worker wait loop (R2), GSettings
backend work, autotools and CMake host identity, §5.1.2's fewer-parameter
callback tolerance.

## Global constraints

- nixpkgs revision: `8ce4ef6cb6f871616146b9fe26d2a5ae594e94fe`, locked through `flake.lock`.
- Emscripten comes from nixpkgs; no compiler patches; never `-sEMULATE_FUNCTION_POINTER_CASTS`.
- Every WASM object is compiled with `ibusWeb.toolchain.commonFlags` (`-fPIC -pthread -fwasm-exceptions`).
- **Derive, don't hardcode:** versions, target prefixes, triples and store paths come from Nix evaluation, never literals. (`emscripten` as the Meson host system is the identity we define, not a derivable value.)
- Dendritic layout: `flake.nix` holds only inputs and `mkFlake … (inputs.import-tree ./modules)`; every `.nix` file under `modules/` is a flake-parts module; modules never `import` each other and share values only through `ibusWeb.*` per-system options and flake outputs.
- import-tree imports only `.nix` files outside `_`-prefixed paths. Non-Nix files sit beside their module under plain names.
- **One directory per component:** `modules/<component>/` holds `overlay.nix` (defining `flake.overlays.<component>`, one gated overlay that may change several nixpkgs attributes), `patches/` (patch files and a README recording their provenance) and `checks/` (`checks/<name>.nix` for a check without sources of its own, `checks/<name>/default.nix` with its sources beside it). Toolchain checks live in `modules/toolchain/checks/`.
- Overlays are gated as `lib.optionalAttrs (prev.stdenv.hostPlatform.isWasm && (prev.stdenv.hostPlatform.useEmscripten or false)) { … }`. The gate reads only the platform; reading `stdenv.cc` recurses. Never define a patched package under another name.
- Outputs: `packages.<system>` holds only ibus-web's own artifacts; WASM builds of nixpkgs packages are reached through `legacyPackages.<system>.pkgsWasm`.
- Emscripten comes from `pkgsBuildBuild` inside the cross set. In `nativeBuildInputs`, reference `pkgsWasm.<pkg>` directly (spliced); use `pkgsBuildBuild` only for store paths interpolated into strings.
- Main modules are linked with `em++` (`$CXX`); C sources are compiled with `$CC -c` first.
- GRegex stays: GLib is built against `pkgsWasm.pcre2`.
- `nix flake check` must pass at the end of every task, and a check must exist for every WASM package we rely on.
- Comments explain why, not what, and never refer to other files, this plan or its history.
- Flakes only see git-tracked files: `git add` before any `nix` command.
- The user edits files in this tree while work runs: leave changes you didn't make in place; never `git checkout`/`restore`/`stash`; commit only the task's files.

### Task 1: Tell Meson the host is Emscripten

Meson's `host_system` comes from nixpkgs' generated cross file, which says
`none` for `wasm32-unknown-none`. GLib's Emscripten patches branch on
`host_system == 'emscripten'`, and Meson itself gives executables a `.js`
suffix only for `emscripten`/`wasm*` systems. Meson reads cross files in
order, later values winning, so a second file needs to say only what
differs. The same file gives Meson Node as its exe wrapper, so Meson can run
test programs and `run()` checks.

**Files:**
- Create: `modules/toolchain/emscripten-meson-hook.sh`
- Modify: `modules/toolchain/cross.nix`, `modules/toolchain/checks/meson-consumer/src/meson.build`

**Interfaces:**
- Consumes: `replaceCrossStdenv` in `modules/toolchain/cross.nix` (its `pkgsBuildBuild`, `baseStdenv.override (old: { … extraNativeBuildInputs = old.extraNativeBuildInputs ++ [ toolchain.emscriptenCacheHook ]; })`).
- Produces: every Meson build in `pkgsWasm` sees `host_machine.system() == 'emscripten'` and `meson.can_run_host_binaries() == true` (Node).

- [ ] **Step 1: Make the Meson check demand it**

In `modules/toolchain/checks/meson-consumer/src/meson.build`, add after `project(…)`:

```meson
if host_machine.system() != 'emscripten'
  error('host system is ' + host_machine.system() + ', expected emscripten')
endif
if not meson.can_run_host_binaries()
  error('Meson has no way to run host binaries')
endif
```

and remove the `name_suffix: 'js',` line from `executable(…)`: Meson adds the suffix itself for an `emscripten` host.

Run: `git add modules && nix build .#checks.x86_64-linux.meson-consumer -L`
Expected: FAIL with `host system is none, expected emscripten`.

- [ ] **Step 2: Write the hook**

`modules/toolchain/emscripten-meson-hook.sh`:

```bash
# Meson reads cross files in order and later values win, so this one only
# carries what differs from nixpkgs' generated cross file.
mesonFlagsArray+=("--cross-file=@crossFile@")
```

- [ ] **Step 3: Add it to the cross stdenv**

In `modules/toolchain/cross.nix`, inside `replaceCrossStdenv`'s `let`, add:

```nix
          # Meson keys Emscripten behaviour (GLib's patches, the .js
          # executable suffix) on the host system, which nixpkgs' cross file
          # reports as the platform's kernel, "none". Node runs what Emscripten
          # links, so Meson can run tests and run() checks.
          mesonCrossFile = pkgsBuildBuild.writeText "emscripten-meson-cross.ini" ''
            [host_machine]
            system = 'emscripten'

            [binaries]
            exe_wrapper = ['${lib.getExe pkgsBuildBuild.nodejs}']
          '';

          emscriptenMesonHook = pkgsBuildBuild.makeSetupHook {
            name = "emscripten-meson-hook";
            substitutions.crossFile = mesonCrossFile;
          } ./emscripten-meson-hook.sh;
```

and change the stdenv's `extraNativeBuildInputs` line to:

```nix
            extraNativeBuildInputs = old.extraNativeBuildInputs ++ [
              toolchain.emscriptenCacheHook
              emscriptenMesonHook
            ];
```

(Keep the file's existing structure; if `extraNativeBuildInputs` is written differently now, add `emscriptenMesonHook` next to `toolchain.emscriptenCacheHook`.)

- [ ] **Step 4: Run the checks**

Run: `git add modules && nix build .#checks.x86_64-linux.meson-consumer -L`
Expected: PASS; the Meson log shows `Host machine cpu family: wasm32` and `Host machine system: emscripten`, and the program still prints `zlib ok` and `ffi 42` (now from `consumer.js` named by Meson).

Run: `nix flake check -L`

- [ ] **Step 1: Write the check program**

`modules/glib/checks/smoke/glib-test.c`:

```c
/* Exercises each GLib library once: GLib (key files, GRegex, threads),
 * GObject (a property notification) and GIO (reading a file back). */
#include <gio/gio.h>
#include <glib-object.h>
#include <glib.h>
#include <stdio.h>

static gpointer add_one(gpointer data) {
  return GINT_TO_POINTER(GPOINTER_TO_INT(data) + 1);
}

static void on_notify(GObject *object, GParamSpec *pspec, gpointer user_data) {
  (void)object;
  (void)pspec;
  *(int *)user_data += 1;
}

int main(void) {
  GKeyFile *keys = g_key_file_new();
  g_key_file_load_from_data(keys, "[engine]\nname=hangul\n", -1,
                            G_KEY_FILE_NONE, NULL);
  gchar *name = g_key_file_get_string(keys, "engine", "name", NULL);
  printf("keyfile %s\n", name);
  g_free(name);
  g_key_file_free(keys);

  GRegex *regex = g_regex_new("^(\\w+)-(\\d+)$", 0, 0, NULL);
  GMatchInfo *match = NULL;
  gboolean matched = g_regex_match(regex, "glib-288", 0, &match);
  gchar *number = matched ? g_match_info_fetch(match, 2) : g_strdup("none");
  printf("regex %s\n", number);
  g_free(number);
  g_match_info_free(match);
  g_regex_unref(regex);

  GThread *thread = g_thread_new("add-one", add_one, GINT_TO_POINTER(41));
  printf("thread %d\n", GPOINTER_TO_INT(g_thread_join(thread)));

  GObject *group = g_object_new(G_TYPE_BINDING_GROUP, NULL);
  GObject *source = g_object_new(G_TYPE_OBJECT, NULL);
  int notified = 0;
  g_signal_connect(group, "notify::source", G_CALLBACK(on_notify), &notified);
  g_object_set(group, "source", source, NULL);
  printf("gobject %d\n", notified);
  g_object_unref(group);
  g_object_unref(source);

  /* Relative to the build directory: the sandbox may have no /tmp. */
  g_file_set_contents("glib-test.txt", "gio", -1, NULL);
  GFile *file = g_file_new_for_path("glib-test.txt");
  gchar *contents = NULL;
  g_file_load_contents(file, NULL, &contents, NULL, NULL, NULL);
  printf("gio %s\n", contents);
  g_free(contents);
  g_object_unref(file);
  return 0;
}
```

```python
"""Compare a Meson test log with the committed baseline.

Only tests listed under must_pass gate the build; excluded tests carry the
reason they cannot run here, and every other result is reported but
informational.
"""

import json
import sys
import tomllib
from pathlib import Path

testlog, baseline_path, out_dir = map(Path, sys.argv[1:4])

results = {}
for line in testlog.read_text().splitlines():
    if line.strip():
        entry = json.loads(line)
        results[entry["name"]] = entry["result"]

baseline = tomllib.loads(baseline_path.read_text())
must_pass = baseline.get("must_pass", {}).get("tests", [])
excluded = baseline.get("excluded", {})

failures = [
    name for name in must_pass if results.get(name) not in ("OK", "EXPECTEDFAIL")
]

by_result = {}
for name, result in results.items():
    by_result.setdefault(result, []).append(name)

summary = [f"{len(results)} tests"]
summary += [f"{result}: {len(names)}" for result, names in sorted(by_result.items())]
summary.append(f"must_pass: {len(must_pass)}, failing: {len(failures)}")
summary += [f"  gating failure: {name} ({results.get(name, 'missing')})" for name in failures]
(out_dir / "summary.txt").write_text("\n".join(summary) + "\n")

proposed = ["# name = result, from this run", "[results]"]
proposed += [f'"{name}" = "{result}"' for name, result in sorted(results.items())]
(out_dir / "proposed-baseline.toml").write_text("\n".join(proposed) + "\n")

print("\n".join(summary))
sys.exit(1 if failures else 0)
```
